## Drox IDE

Fork de Code OSS, avec un moteur agent en **Rust** embarqué dans l’éditeur.

Il lit le dépôt, planifie, modifie le code. Le modèle, c’est **le tien** : Ollama sur ta machine, ou l’endpoint que tu configures. Les sessions restent dans le profil local. Pas de télémétrie Drox.

**Stack** — TypeScript · Electron · Rust (`drox --serve`)

## Pourquoi

Les agents dans l’éditeur sont devenus indispensables — souvent derrière un compte, un cloud et les règles d’une plateforme.

Drox fait l’inverse : le même confort d’agent, dans une pile **lisible, forkable, auditable** (MIT). L’enjeu est de tenir la boucle (LLM, outils, permissions, sessions) dans un binaire embarquable, branché sur ton runtime, pas sur le nôtre.

- Données et sessions **sur ta machine**
- LLM **que tu choisis**
- Code **que tu peux lire**

Suivre l’avancement : [@droxdev](https://www.instagram.com/droxdev/)
